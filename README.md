# 🌐 Personal Portfolio & Interactive CV — Ana Colina Arismendi

Source code repository hosting my personal website and bilingual interactive resume (English / Spanish).

🔗 **Live Website:** [Explore Online Portfolio & CV](https://anacolinaarismendi.github.io/ana.arismendi.github.io/)

---

## 🛠️ Built With

* **Semantic HTML5 & Responsive CSS3:** Mobile-first, fully responsive layout tailored for smartphones, tablets, and desktop displays, featuring high-contrast accessibility and a modern corporate design.
* **Vanilla JavaScript:** Fast, client-side language toggle enabling seamless, real-time switching between English and Spanish without page reloads.
* **Python (`generate_html.py`):** Automated build script to programmatically compile and update resume sections, skills, and work experience.
* **GitHub Pages:** Continuous static web hosting and automated deployment directly from the `main` branch.
